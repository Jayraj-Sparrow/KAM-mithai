# KAM · The only thing kam is the sugar.

Concept website for KAM, a mithai brand with no added sugar. Plain HTML, CSS and JavaScript; animations use GSAP from a CDN. No build step.

- `index.html` – the page
- `styles.css` – look and layout
- `app.js` – cart, checkout, Spot the Sugar game, animations, and the settings at the top (`CONFIG.whatsapp`)
- `assets/` – photos (see `assets/README.md` for the file names)

## Hosting on GitHub Pages
Settings → Pages → Source: **Deploy from a branch** → Branch: **main** / **(root)** → Save.
The site goes live at `https://<username>.github.io/kam-mithai/` within a minute or two.

## Updating
Edit a file on GitHub (pencil icon) and commit. Pages redeploys automatically.
